Pointer basics

A pointer is a variable that stores the memory address of another variable. Declare one with an asterisk, and take an address with the ampersand operator.

Dereferencing a pointer with * reads or writes the value stored at that address. Always initialise a pointer before you dereference it.

Try it: declare an int, point to it, and print the value through the pointer.
