1. Task Description

Problem Statement

Write a C program that acts as a simple calculator. The program should take an operator (+, -, *, /) and two operands (floating-point numbers) as input from the user, and print the result of the operation formatted to two decimal places.

Requirements

  • Use a switch statement to handle the different operators.
  • Handle division by zero gracefully (print exactly "Error: Division by zero").
  • Input format: [operator] [operand1] [operand2]
