Function Parameters

Parameters act as variables inside the function. They are specified after the function name, inside the parentheses. You can add as many parameters as you want, just separate them with a comma.

Learning Objectives

  • Understand how to pass data to functions
  • Differentiate between arguments and parameters
  • Implement a function with multiple parameters
